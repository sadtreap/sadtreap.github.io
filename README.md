# sadtreap.github.io

[sadtreap's blog](https://sadtreap.github.io/), built on [AstroPaper](https://github.com/satnaing/astro-paper).

```bash
pnpm install
pnpm dev
pnpm build
```

`pnpm build` checks types, builds the site, and rebuilds the search index.
It also copies the current index into `public/pagefind` for use with `pnpm dev`.

Run `pnpm lint`, `pnpm format:check`, and `pnpm test` before submitting changes.
